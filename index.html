Build with it

One script and one tag let a web page take a phone as its controller. This page does, with the same SDK.

<script type="module"
  src="https://obpal.blackboxes.net/embed.js"></script>
<obpal-remote app="My scene" seats="4"
  modes="face.trackpad face.wii"></obpal-remote>
