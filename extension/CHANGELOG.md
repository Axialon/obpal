# ob.Pal Link changes

## 1.8.0

This store update includes 1.7.0, released on GitHub but never submitted to the Chrome Web Store. It follows the published 1.6.2 store version.

- The pairing QR reassembles into the connection seal and stays in the same surface. The shared surface supports separate seals for multiple phones; Link's popup currently shows the active phone's seal. Add a phone to return to the QR, or cancel to return to its seal.
- An icon row keeps pairing actions together, with the Pair → Enable → Try journey, the dot demo, the Windows install guide and clearer browser and PC copy from 1.7.0.
- The store and package icons use the same logo as the site. Small toolbar sizes adjust only stroke weights.
- Refreshed store images use Carbon glass, device dots and a still dot-wave link around current UI captures. The update kit marks every field and image against the submitted 1.6.2 listing.
- The seal remains a comparison aid, not certification or permission to control a tab or PC.

## 1.7.0

- Pair → Enable → Try guidance, a Gamepad API dot demo and clearer browser and PC scopes.
- Living Constellation surfaces, shared dot material and timing tokens, with the existing connection seal and 1200 ms handshake preserved.
- A Windows Desktop install companion receives only Link's sanitized helper status. Its Check in Link action opens PC settings; it cannot send input or allow a phone.
- Qualified viewer, vibration and panic-key copy. PC Allow/Deny, held-input releases and the panic key retain their existing behavior.
