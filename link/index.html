01

Pair

Pin Link from your browser’s Extensions menu. Open it on a page and scan its QR with your phone.

Check the camera shows obpal.blackboxes.net. The controller opens in your phone’s browser.

02

Enable

Turn on This tab in Link. Pairing alone leaves input off.

Compare the connection seal on both devices. PC access is a separate choice.

03

Try

Open the dot demo, reopen Link, choose Controller and enable This tab. Move the left stick on your phone.

Optional · Windows

Take it to the PC.

ob.Pal Desktop adds mouse, keyboard and typing in allowed programs or the whole PC. Allow or deny each phone separately. Elevated Windows apps may refuse input.

Set up ob.Pal Desktop

Ctrl+Alt+Backspace stops input from the phone. macOS is coming soon.

Manual install

  1. ExtractUnzip into a folder you’ll keep.
  2. LoadOpen chrome://extensions, turn on Developer mode, choose Load unpacked and select that folder. In Edge, use edge://extensions.
  3. Pin and returnPin Link from Extensions, then open the dot demo. Updates need a new zip and a reload.
