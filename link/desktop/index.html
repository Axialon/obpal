ob.Pal Desktop · optional · Windows

A phone.
Your PC, by permission.

Install Desktop. Return to Link. Choose what to allow.

Open Link to check Desktop. This page has not checked the helper.

Add and pin ob.Pal Link first. The page only receives its helper status; it cannot control your PC.

01

Download

Get the Windows x64 zip from the project’s releases. Unzip it into a folder you’ll keep.

Download for WindowsReview the release
02

Read the warning

Desktop is unsigned. Windows may show an unknown publisher or SmartScreen warning. Signing is being investigated.

Proceed only after checking the source and release. If your organization blocks unsigned apps, ask its administrator; don’t bypass its policy.

03

Install, then check

Double-click install.cmd in the extracted folder. Read the command window for errors. Leave the folder in place.

Back in Link, choose PC and grant native-messaging permission when asked. Link then checks the helper.

A separate permission

Allow this phone?

Pair your phone in Link. Compare its connection seal, then choose Allow or Deny when it asks for PC access. Allowing the phone does not enable every program.

Choose an allowed program, or turn on Whole PC in Link’s PC settings. You can deny the phone later in Phones.

Keep a way to stop

Stay in control.

The default panic key is Ctrl+Alt+Backspace. Check Link reports it as available before enabling PC input. It stops keyboard and mouse input from the phone.

Link also has Pause all and per-program removal.

Back to Link · pair, enable, try

Update or remove

Switch Link away from PC and close its settings before replacing Desktop’s files. To remove it, run uninstall.cmd in its folder; it removes the helper, its settings and that folder.
