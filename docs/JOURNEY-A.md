# Journey stage A

Direction C, Living Constellation, is now the Link route language. The illustration explains phone → browser with a muted, labeled optional PC branch; it does not report a live connection. The popup reports actual pairing and enablement separately. The Gamepad API demo receives input only after the person enables that tab. Its Try button opens a page, never grants activeTab or broad permissions by itself.

The companion's exact top-level route receives a sanitized helper status from an isolated Link content script. The service worker validates its own extension ID, sender origin, path, frame and tab. Status reads do not connect to native messaging. Check in Link opens the existing PC settings, where the existing permission and native connection behavior applies. Nothing exposes storage.session or input/configuration commands to the page. Page status is guidance, never authorization.

The audit's eighteen findings are disposed of below. Deferred work is explicit rather than implied by the new visual language.
